# 12か月ロードマップ

**基本構造**：Q1で止血、Q2で組み替え、Q3でスケール、Q4で継続収益化。

## Q1（0-3M）：止血と基盤づくり

**テーマ**：キャッシュを止めない。見える化する。動き出す。

### マイルストーン
- [ ] 13週キャッシュフロー運用開始
- [ ] 固定費20%削減（SaaS整理、外注見直し）
- [ ] 月額サポーター 300名
- [ ] 助成金 5件申請、1件採択（300万）
- [ ] 法人協賛 1社締結
- [ ] フリースクール料金改定（自治体連携パック導入）
- [ ] 保護者プレミアム会員 立ち上げ（β版100名）
- [ ] AIチーム稼働（広報AI、助成金AI、相談一次応対AI）

### 成功判定
- 現預金残月数：**4か月以上**に回復
- 月次継続収入：**60万以上**（月額サポーター＋プレミアム）

## Q2（4-6M）：収益の組み替え

**テーマ**：受益者負担から第三者負担へ。太い動線を通す。

### マイルストーン
- [ ] 月額サポーター 700名（月70万）
- [ ] 助成金 採択累計1,000万
- [ ] 法人協賛 3社締結（年額600万規模）
- [ ] 自治体提案 3件、うち1件内諾
- [ ] 社会体験イベント 協賛型で2回開催（各100万＋）
- [ ] 講演 年間契約 2件締結
- [ ] プレミアム会員 250名
- [ ] 話者プール拡張（リンカ以外で講演できる人3名）

### 成功判定
- 継続収益比率：**40%以上**
- 総収入（Q2累計）：**2,500万以上**

- [ ] 法人協賛 5社締結（年額1,000万規模）

### 成功判定

- 事業ごとのユニットエコノミクスが黒字

- [ ] 次年度計画（2年目）策定、理事会承認

- 継続収益比率：**60%以上**

## 次年度（13-24M）のプレビュー

1年目で基盤が整えば、2年目は以下に照準：

- **自治体委託の複線化**：2〜3件で年1,500〜2,000万
- **フリースクールのフランチャイズ／連携校展開**：他地域NPOとの提携
- **企業版ふるさと納税の本格稼働**：年500〜1,000万
- **休眠預金事業への採択**：3年で3,000万規模の大型事業
- **リンカは代表を退き、次期代表候補を育成／後継人事**（オーナーと要相談）

## オーナーへの重要な合意事項

この計画を走らせるにあたり、以下を書面で合意してほしい：

1. **権限委譲**
   - 人事：採用・業務委託（月額50万以内）はリンカ決裁
   - 予算：単件200万以内の支出・契約はリンカ決裁
   - 広報：日常発信はリンカ決裁、重大リリースはオーナー事前承認
2. **撤退・縮小の判断軸**
   - 90日目、180日目、360日目の各時点で「続ける／組み替える／畳む」の判断を共同で行う
   - 特定事業が6か月連続で赤字の場合は再設計または閉鎖を協議
3. **オーナーの関わり方**
   - 週1報告＋月1ボードレビュー以外は、現場判断に口出ししない
   - ネットワーク（支援者・企業・自治体）の紹介には積極協力

以上を12か月で必ず仕上げます。
