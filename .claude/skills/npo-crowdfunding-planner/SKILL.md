# NPO Crowdfunding Planner（クラウドファンディング企画・原稿作成）

## 役割

シード期NPOにとって、クラウドファンディングは「資金 + 認知 + 創業ストーリーの記録 + 次の助成金審査の実績」を一度に作れる最強の打ち手。
このスキルは企画設計と本文ドラフトを生成する。

## プラットフォーム選定

| プラットフォーム | 特徴 | 向いているケース |
| --- | --- | --- |
| READYFOR | 教育・福祉のNPO案件に強い、All-or-Nothing型 | 目標額 200〜800万、本気の宣言型 |
| GoodMorning（CAMPFIRE系） | 社会貢献特化、All-In型あり | 目標額 100〜500万、コミュニティ密着型 |
| CAMPFIRE | 最大手、案件多様 | 認知拡散・話題性重視 |

**シード期NPOの推奨**：READYFORで300〜500万、All-or-Nothing型、実施期間60日。
理由：達成すれば「READYFORで○○万円達成」という社会的証明が極めて強く、次の助成金応募で書ける。

## 企画設計フレーム

1. **目的**：何のために、なぜ今、いくら必要なのか（具体プロジェクト型が通る）
2. **ストーリー**：創業の動機、最初の35家庭のエピソード、次に届けたい家族
3. **使途**：設備、教材開発、奨学枠創設、人件費（人件費単独はNG、プロジェクト名と紐付ける）
4. **目標額の設計**：
   - 必達ライン（オーナー貸付や自己資金で必ず集める = 全体の40%）
   - チャレンジゾーン（既存サポーターの拡張 = 30%）
   - 拡散ゾーン（メディア・口コミ = 30%）
5. **リターン設計**：
   - 1,000円：感謝メール、活動報告
   - 3,000円：上記＋オリジナルステッカー、ニュースレター3か月
   - 5,000円：上記＋活動報告会オンライン招待
   - 10,000円：上記＋名前掲載、書籍寄贈
   - 30,000円：オンライン1on1相談（リンカ）
   - 100,000円：法人協賛枠・サイト掲載・社員向けセミナー1回
   - **物販系リターンは作らない**（発送コストが利益を食う）
6. **マイルストーン**：開始3日で30%（このラインを超えると達成率8割）、20日で50%、最終週で残り

## 原稿構成（READYFOR テンプレ準拠）

1. **プロジェクト概要**（300字、画像付き）
2. **自己紹介**：団体の設立経緯、代表のストーリー
3. **解決したい社会課題**：不登校児童生徒の数、孤立、学びの機会
4. **これまでの活動**：35家庭のエピソード（匿名化）、子どもの声、保護者の声
5. **このプロジェクトでやること**：具体的に何を、いつまでに、何人に
6. **資金の使い道**：費目と金額の内訳（管理費・手数料含めて100%表示）
7. **リターン**：上記の段階別リターン
8. **応援メッセージ**：可能なら有識者・著名人・連携先のコメント
9. **最後に**：呼びかけ、SNS拡散のお願い

## 文体・トーン

- 一人称：「私たち」（団体）と「私」（リンカ／代表）を使い分け、人格を出す
- 過度な感情訴求は避け、**具体的な事実と数字**で語る
- 「助けてください」より「**一緒に作ってください**」
- 専門用語（不登校特例校、出席扱い制度など）は初出時に簡潔説明

## 公開前チェックリスト

- [ ] 写真：受益家庭の写真は本人同意済か（顔出しNGなら後ろ姿・イラスト）
- [ ] 個人情報：エピソードに個人特定要素が残っていないか
- [ ] 数字の正確性（35家庭、設立日、月謝額など）
- [ ] 寄付控除の可否を明記（認定NPO法人かどうか）
- [ ] リターン履行スケジュールが現実的か
- [ ] 達成しなかった場合の対応（All-or-Nothing型なら全額返金）
- [ ] 終了後の活動報告計画（1か月後、3か月後、半年後）

## プロモーション計画（並走で必ず）

- 開始2週間前：既存35家庭・支援者へ予告メール、SNSティザー
- 開始日：一斉配信（メール・LINE・SNS）、目標は初日に20〜30%到達
- 開始1週間：地方紙・教育系メディアへプレスリリース
- 中盤：YouTube/Instagramライブで進捗報告
- 終盤7日：駆け込みCTAを毎日、達成見込みで支援者に追加コール

## 出力

- 企画書（A4 4枚、上記フレーム）
- READYFOR本文ドラフト（5,000〜8,000字）
- リターン一覧表
- 60日プロモーションカレンダー
