# KPIダッシュボード

## 3つの北極星指標（オーナー報告で毎週見る）

### ① 現預金残月数 ＝ 現預金残高 ÷ 月次固定費
- **目標**：6か月以上を常時維持（下限アラート3か月）。
- **狙い**：キャッシュが尽きないこと。NPOの生存線。
- **アクション閾値**：
  - 3か月を切ったら緊急コスト削減＋オーナー報告
  - 2か月を切ったら一部事業の停止／外部借入検討

### ② 継続収益比率 ＝（月額サポーター＋サブスク＋自治体委託＋年間協賛）÷ 総収入
- **目標**：12か月で60%以上。
- **狙い**：単発・偶発収入から脱却し、毎月予測可能なキャッシュを作る。

### ③ 受益者インパクト ＝ 実利用者数 × NPS／満足度
- 子ども（フリースクール在籍者、イベント参加者）
- 保護者（コミュニティ会員、相談利用者、セミナー受講者）
- 教育・支援者（講演受講者、研修受講者）
- **目標**：年間 受益者 延べ10,000人／NPS 50以上。

## 週次レビュー（オーナー向け）

**毎週 火 or 木の朝 30分**、以下のフォーマットで報告：

```
【今週の数字】
- 現預金残月数：X.X か月（先週比）
- 新規サポーター：N 名／累計 N 名
- 主要パイプライン動き：（助成金・法人・自治体）

【今週のハイライト】
1. 良かったこと（受益者の声、新契約、等）
2. 困っていること／判断を仰ぎたいこと
3. 来週やること

【論点】
- オーナーに判断してほしいこと（0〜3件）
```

## 月次ボードレビュー（理事・監事向け）

月1回、上記に加えて：

- 事業別P/Lの月次実績と予実差異
- ファンドレイジングパイプラインの進捗
- 受益者インパクトの定性・定量レポート
- リスクレジスター（コンプライアンス、情報セキュリティ、人的リスク）

## 年次評価

- 事業報告書（法定）
- **インパクトレポート**（ソーシャルインパクト評価）を別途作成。寄付者・企業・自治体への説明責任ツールにする。
  - ロジックモデル：投入 → 活動 → アウトプット → アウトカム → インパクト
  - 代表的アウトカム：学校復帰率、進路決定率、保護者の孤立解消、子どもの自己肯定感変化（尺度測定）
