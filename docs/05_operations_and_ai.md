# 業務オペレーションとAIチーム編成

## 方針

NPOは人件費が重く、代表・一部スタッフに業務が集中しがち。
**人は「ケア」と「現場」と「意思決定」に集中し、AIに作業を載せ替える**。
目標：同じ人数・同じ予算で**生産量を2〜3倍**にする。

## AIチーム編成（Claude Agent SDK / Claude Code ベース）

### 1. 広報AI（コミュニケーション）
**役割**
- SNS（Instagram／X／Facebook）の日次投稿ドラフト
- メールマガジン（月2回）の企画・ドラフト
- プレスリリース下書き
- LPコピー、ブログ記事のドラフト
- 寄付ページ・協賛ページのA/Bテスト案

**人との分担**
- AIが70%（情報収集〜ドラフト〜画像生成指示）
- 人が30%（受益家庭の声の確認、最終トーン調整、公開承認）

**KPI**
- 投稿数：週7本
- メルマガ開封率 30%以上
- 寄付LP流入からのCVR 2%以上

### 2. 助成金AI（リサーチ＆申請）
**役割**
- 公募中助成金の日次クロール（内閣府、都道府県、民間財団のRSS／ページ巡回）
- 候補案件の採択可能性スコアリング
- 申請書ドラフト作成（事業計画・予算・成果指標）
- 過去の採択実績ベースの言い回しライブラリ管理

**人との分担**
- AIが80%（リサーチ〜ドラフト〜予算計算）
- 人が20%（事業の固有ストーリー差し込み、最終校正）

**KPI**
- 年間申請数 20件
- 採択率 25%以上
- 申請1本あたりの人の工数 8時間以下（従来比1/3）

### 3. 相談一次応対AI（保護者の初回応対）
**役割**
- LINE公式アカウント／問い合わせフォームの一次応対
- 保護者の状況をヒアリング（構造化）
- 緊急度トリアージ（自殺念慮・虐待等の兆候があれば即座に人の相談員にエスカレ）
- FAQへの即答
- 面談予約の受付

**人との分担**
- AIが応対の70%を完結（FAQ・情報提供・予約）
- 30%は有人相談員に引き継ぎ（深い悩み、個別性の高いケース）

**重要な設計**
- **セーフガード**：緊急ワード（死にたい／消えたい／殴られる等）の検出時は即座に人に切り替え＋緊急連絡先（いのちの電話、児童相談所189）を提示。
- **個人情報の扱い**：相談内容は暗号化保管、同意なき外部共有はしない。

**KPI**
- 初回応答までの平均時間 1時間以内（従来24h超）
- 面談予約転換率 15%以上
- 有人エスカレ率の適正性（定期レビュー）

### 4. 教材AI（フリースクール）
**役割**
- 個別学習プランの生成（学年・得意不得意・興味に応じて）
- 授業用スライド・ワークシートのドラフト
- 進捗レポートの生成（保護者・在籍校提出用）
- 出席扱い申請用の学習記録の整形

**人との分担**
- AIが素材生成、現場スタッフが個別性を加味して仕上げ。

**KPI**
- 教材準備の工数 1件1時間以下（従来4時間）
- 出席扱い認定率 90%以上

### 5. 経営ダッシュボードAI（KPI・資金繰り）
**役割**
- 会計ソフト（freee／マネーフォワード）からのデータ取得
- 月次KPIレポート自動生成
- 13週キャッシュフロー更新
- 異常値検知アラート（現預金残月数が閾値割れなど）

**人との分担**
- AIが集計と作図、リンカが解釈とアクション判断。

**KPI**
- 月次レポート作成の工数 2時間以下
- 資金ショート兆候の検知を2週間前

### 6. コミュニティモデレーションAI
**役割**
- 保護者コミュニティ内の投稿監視（誹謗中傷、個人情報露出等の検知）
- 質問への下書き回答（人の専門家が監修して投稿）
- プレミアム会員の関心グルーピング・コンテンツ企画提案

**人との分担**
- モデレーション判定はAIが1次、人が最終判断。
- 相談回答は専門家（児童精神科医・元教員など業務委託）が監修。

## スキル（専用エージェント）設計

Claude Agent SDKのSkillとして、以下を整備する想定：

| スキル名 | 用途 |
| --- | --- |
| `npo-grant-drafter` | 助成金申請書のドラフト生成 |
| `npo-sponsor-pitch` | 法人協賛の提案書生成 |
| `npo-parent-triage` | 保護者相談の一次トリアージ |
| `npo-learning-plan` | 個別学習プラン生成 |
| `npo-kpi-dashboard` | 月次KPIレポート生成 |
| `npo-storytelling` | 受益家庭の声を活動報告・広報文に編集 |

これらはいずれも「団体固有の情報」（ミッション、過去事例、語り口、承認フロー）をSkill内に構造化して保持する。新しいスタッフやインターンも、Skillを呼び出せば団体の型で仕事が進む。

## 人の体制（想定）

| 役割 | 人数 | 主担当 |
| --- | --- | --- |
| 代表（リンカ） | 1 | 戦略、資金調達、自治体・大口法人対応、オーナー報告 |
| 事業責任者（フリースクール＋イベント） | 1 | 日々の運営、スタッフ管理 |
| 相談員（有人応対） | 2（業務委託含む） | AIからのエスカレ対応、深い相談 |
| 広報・ファンドレイジング担当 | 1 | AI監修、プレス・SNS・メルマガ運用 |
| 経理・バックオフィス | 0.5（業務委託） | 会計、労務、契約管理 |

**合計 5.5名＋AIチーム**で、現在の業務量の1.5〜2倍を捌く想定。

## 情報セキュリティとガバナンス

- 保護者・子どもに関する情報は **匿名化／最小化／目的外利用禁止** を徹底。
- AIへの情報投入時は、個人特定情報を除去した上で処理するフローを設計。
- 月1回、AI応対ログのサンプリングレビュー（相談員・リンカで実施）。
- 個人情報保護方針を改訂し、AI活用の記載を明示（信頼の可視化）。
