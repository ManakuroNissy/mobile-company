# 戦略再キャリブレーション（2026-04-22）

オーナーから追加された前提：

- NPO設立：**2025年10月24日**
- 事業開始：**2026年2月**（事業稼働 約2.5か月）
- オンラインフリースクール：**会員35名**
- 助成金・協賛金の獲得実績：**ゼロ**

これは「経営失敗からの立て直し」ではなく、**「シード期NPOのランウェイ管理＋PMF深掘り」フェーズ**の問題です。
同梱の `README.md` 以下7ドキュメントの方針は維持しますが、**順序・優先度・初年度の数字目標**を以下のとおり差し替えます。

## 1. 状況の再評価

### ポジティブ要素（過小評価しないこと）
- 事業稼働2.5か月で**会員35名**は、不登校支援フリースクールとしては**強い初動**。
  - 仮に平均月謝25,000円なら **MRR約87.5万円**。年換算で約1,000万のサブスクリプション基盤がすでにある。
  - 月15名前後の純増ペース＝**口コミとSEOの初期エンジンがすでに回っている**示唆。
- 設立直後で「創業ストーリー」と「初期メンバー（35家庭）」という、最も換金性の高い**物語資産**を持っている。

### 厳しい現実
- 事業稼働3か月未満は、**助成金審査の最大の弱点**：
  - 多くの助成金は「過去2〜3年の実績」「決算書2期分」を要件にする。
  - 「実績ゼロ」のままでは、大型助成金は構造的に通らない。
- 法人協賛も同様に、**信用ゼロからのコールドアプローチは成功率1%以下**。
  - 紹介・既存接点・創業ストーリーで突破口を開く以外に道はない。
- ランウェイは現預金 ÷ 月次バーンで決まるが、現状の数字は未確認（最優先で要把握）。

### 「火の車」の正体（仮説）
- 法人設立費、システム導入費、初期採用費、広告宣伝費の**前倒し投資**を、
  - 35名×月謝のMRR（約87.5万）と
  - オーナー出資・自己資金
  だけで賄っている状態と推察。
- 助成金・協賛がゼロなので、**第三者からの「補填」がまったく入っていない**ことが致命傷。
- バーンを抑える余地はあるが、**事業成長の芽（広告／採用／教材開発）を切ると未来が消える**。

→ 治療方針は **「コスト圧縮よりランウェイ延伸」** が優先。

## 2. 優先順位の差し替え

元の90日プランは「止血→組み替え→自治体・法人」でしたが、シード期の現実に合わせて **3レーン並走** に変更します。

### レーンA：**ランウェイ確保（最優先・48時間以内に着手）**

「実績ゼロでも入る金」を **30〜90日で** 確保する。

1. **オーナー貸付の検討**
   - 一時的な資金繰りのため、オーナーからの**短期貸付**（無利子または低利子、6〜12か月）を相談。
   - 立ち上げ期NPOでは創業者・オーナーからの貸付は通常の選択肢。
2. **日本政策金融公庫「ソーシャルビジネス支援資金」**
   - NPO法人も対象。創業期向けの融資枠あり。実績ゼロでも事業計画で勝負できる。
   - 上限：7,200万、運転資金は5年〜7年返済。
3. **福祉医療機構（WAM）の貸付**
   - 助成金とは別に**福祉貸付事業**がある。NPO法人も対象。
4. **クラウドファンディング（30〜90日）**
   - 創業期NPOで「実績ゼロ」を**逆手に取れる唯一の手段**。
   - 切り口：「2026年2月にスタート、すでに35家庭の不登校の子を支えている。次の100家庭に届けたい」
   - プラットフォーム：READYFOR（教育・福祉強い）、GoodMorning（CAMPFIRE系、社会貢献特化）
   - 目標額：300〜500万円（達成率の見込みから設計）
   - **副産物**：創業ストーリーの拡散、初期サポーター名簿、メディア露出。これは「次の助成金審査の実績」になる。
5. **既存35家庭からの月額サポーター転換**
   - 既存会員の保護者・親族・祖父母世代に、**月1,000円〜の継続寄付**を呼びかけ。
   - 35家庭 × 平均1.5契約（家庭+祖父母）× 1,500円 = **月7.8万**を初動で確保しうる。

→ **A4枚の「90日資金繰り表」をオーナーと共有し、上記5レーンの累計で「6か月以上のランウェイ」を確保する**のが90日のゴール。

### レーンB：**実績の高速立ち上げ（90〜180日）**

助成金・協賛で「初の1件」を取るために、**実績ゼロを実績アリに変える短期施策**を打つ。

1. **小型助成金から取りに行く**
   - 上限30〜100万の地域助成・財団助成に集中（採択ハードルが低い）。
   - 候補例：
     - 都道府県・市町村の市民活動助成（月単位で公募あり）
     - 中央共同募金会のNPO基盤強化助成
     - 地域の信用金庫・地銀のCSR助成（10〜50万）
     - パブリックリソース財団、SVP東京などの伴走型助成
   - **小さくても1件採択されると、次の助成金で「採択実績あり」と書ける**。これが信用の階段の最初の段。
2. **法人協賛の「最初の1社」を、コールドではなく既存接点で取る**
   - オーナー、リンカ、理事、35家庭の保護者の**個人的なツテをロングリスト化**（最低50社）。
   - 親族・友人の経営者、地元商工会、保護者勤務先のCSR担当、卒業校のOB会など。
   - **金額は問わない（10万でも30万でも）**。1社目の実績が出れば、2社目以降は格段に提案が通る。
3. **メディア露出を意図的に作る**
   - 地方紙、ローカルテレビ、教育系メディア（リセマム、こども教育新聞、不登校新聞）。
   - 「設立半年で35家庭を支援するオンラインフリースクール」は、地方紙には十分にニュース。
   - 露出を **次の助成金審査の参考資料** として保管。
4. **インパクトレポート（ライト版）**
   - 90日時点で **A4 4ページのレポート** を作る。
   - 受益者数、典型的な家庭の変化（匿名化）、定性アンケート結果、財務サマリ。
   - これを助成金応募・協賛提案・サポーター獲得すべてに添付する。

### レーンC：**MRR成長の継続（事業の根っこ）**

ランウェイ確保で時間を稼ぎ、その間に**事業のMRRを成長させ続ける**ことが本丸。

1. **35家庭からの学びを榨り尽くす**
   - 全家庭に**1on1ヒアリング**（30分）を90日以内に完遂。
   - 入会の決め手、継続の理由、改善要望、紹介可能性を構造化して把握。
   - これがプロダクト改善・広告コピー・紹介プログラム・LTV向上のすべての源泉になる。
2. **紹介プログラムの導入**
   - 既存家庭からの紹介で1か月分の月謝割引、紹介された家庭にも初月割引。
   - 不登校支援は**家庭間の口コミが極めて強く効く領域**。最大の獲得チャネルになる。
3. **広告は止めない、むしろ最適化**
   - シード期にバーン削減を理由に広告をゼロにすると、未来の現金が消える。
   - 月10〜30万の広告予算を維持し、CACとLTVをモニタする。
4. **保護者プレミアム会員の早期立ち上げ（90日以内にβ）**
   - 35家庭は最初の有料会員候補プール。
   - 月2,980円で「保護者向けの相談・セミナー・コミュニティ」を提供開始。
   - 35家庭の50%転換 = 月5.2万の追加MRR。小さくても**サブスク2本目**ができる事実が大きい。

## 4. 実績ゼロからの「信用の階段」設計

助成金・協賛の獲得は、**信用の階段を1段ずつ登る**プロセスです。実績ゼロから一気に大型は取れません。
シード期NPOの王道ルート：

```
クラウドファンディング達成
        ↓
小型地域助成（10〜50万）
        ↓
中型民間助成（100〜500万）
        ↓
大型助成・休眠預金（1,000万〜）

並走で：
個人ネットワーク経由の小口協賛（10〜50万）
        ↓
中堅地元企業の年間協賛（100〜300万）
        ↓
上場企業のサステナ協賛（500万〜）
```

それぞれの段で**1〜2件の実績を作って、次の段の応募書類に書ける状態**にしてから登る。
12か月で2〜3段登れれば、24か月目には大型助成・大型協賛が射程に入ります。

## 6. 既存35家庭：シード期の最大の資産

数字を超えた価値があります：

- **物語**：「2026年2月からの最初の35家庭」というラベルは、生涯にわたって団体の創業期を象徴する。
- **声**：彼らの保護者の声・子どもの声は、助成金・クラファン・協賛・自治体提案のすべてに活きる。
- **紹介源**：1家庭が平均1.5家庭を紹介すれば、12か月で50〜80家庭に複利成長する。
- **コミュニティの核**：保護者コミュニティ（プレミアム会員）の創業メンバーになりうる。

→ **35家庭への接し方が今後12か月の命運を握る**。
広告でも助成金でもなく、**「いま在籍している家庭をきちんと見続けること」**がシード期の最強戦略です。
これだけは、リンカもAIチームも肩代わりせず、現場スタッフとリンカが直接やり続けます。
