## 0. 前提と現状認識（仮説）

- キャッシュが火の車＝「単月赤字が続いている」もしくは「売掛/入金ラグと固定費ミスマッチで資金繰り難」のいずれか、あるいは両方。
- NPO特有のパターンとして以下が疑われる：
  - 受益者（子ども・保護者）から十分な対価を取れていない（使命と収益の混同）。
  - 助成金依存で、年度末に資金が細る／単年度プロジェクト型で持続性がない。
  - 法人協賛・自治体委託という「BtoB/BtoG の太い動線」が未整備。
  - 事業が属人化していて、代表・一部スタッフが講演・運営・相談を全部抱えている。

この仮説は90日で潰します（オーナーへの週次報告で検証）。

## 1. 立て直しの要諦（リンカの方針）

1. **ミッションは死守し、ビジネスモデルは組み替える**。
   不登校の子と保護者に価値を届けることは絶対。収益源は「受益者負担だけ」に頼らず、価値を認める第三者（企業・自治体・寄付者）に払ってもらう構造に移す。
2. **3層収益構造に再設計する**。
   - 直接収益（受益者の月謝、イベント参加費、セミナー有料化）
   - 第三者収益（法人協賛、自治体委託、助成金）
   - 継続収益（月額サポーター寄付、遺贈・休眠預金）
3. **4事業を「個別最適」から「ファネル」に再編する**。
   講演→保護者コミュニティ→フリースクール／イベント、という流入〜定着の一本の導線に変える。LTVと紹介率で回す。
4. **AIチームで人件費のレバレッジを上げる**。
   相談応対・広報・助成金申請・教材準備など、現在ボトルネックになっている作業をAIに載せ替え、人はケアと現場に集中する。

## 3. 事業ごとの打ち手（要約）

詳細は `docs/03_revenue_model.md`。

- **オンラインフリースクール**：家庭月謝のみ→「家庭月謝 + 自治体補助 + 企業奨学金」の三階建て。在籍証明・出席扱い連携で自治体側の予算を取りに行く。
- **子ども向け社会体験イベント**：参加費依存→「企業協賛が主、参加費は低額 or 無料」に切替。SDGs/人的資本開示のニーズを持つ企業に売る。
- **講演・講話**：単発・低単価→「教育委員会・PTA連合・企業研修」向け年間契約パッケージ化。1件15万〜40万の階段を作る。
- **保護者コミュニティ／オンラインセミナー**：無料運営→「無料の入口＋月額サブスクの本体＋年次カンファレンス」の3層フリーミアム。

## 4. ファンドレイジング

詳細は `docs/04_fundraising.md`。

- 月額サポーター（継続寄付）の立ち上げ。目標：12か月で月100万円。
- 助成金：WAM、赤い羽根、ベネッセ教育こども基金、ソーシャル・インパクト・ボンド等を年間カレンダー化。
- 企業協賛：人的資本開示・D&I・ウェルビーイング文脈で5〜10社にアプローチ。
- 休眠預金・ふるさと納税・遺贈寄付は12か月目以降に仕込む。

## 5. 業務・AIチーム

詳細は `docs/05_operations_and_ai.md`。

AIチーム編成（社内の人＋専用Claudeエージェント）：

- **広報AI**：SNS投稿、プレスリリース下書き、メールマガジン。
- **助成金AI**：公募情報の日次クロール、申請書ドラフト。
- **相談一次応対AI**：保護者からの初回問い合わせのトリアージ（人の相談員に繋ぐ判断込み）。
- **教材AI**：フリースクールの学習コンテンツ下書きと個別化。
- **経営ダッシュボードAI**：月次KPI集計、資金繰り監視。

## 6. KPIダッシュボード

詳細は `docs/06_kpi.md`。

3つの北極星指標：

1. **現預金残高 / 月次固定費** ＝ 何か月持つか（6か月以上を死守）
2. **継続収益比率** ＝（月額サポーター＋サブスク＋自治体委託）÷ 総収入（12か月で60%以上）
3. **受益者数 × 満足度**（子ども実利用者、保護者会員、講演受講者）

## 7. 12か月ロードマップ

詳細は `docs/07_roadmap_12m.md`。

- Q1（0-3M）：止血。キャッシュ残月数を6か月以上に回復。
- Q2（4-6M）：収益の組み替え。自治体・法人の太い動線を2本通す。
- Q3（7-9M）：スケール。フリースクール定員2倍、講演年間契約3件。
- Q4（10-12M）：継続収益化。月額サポーター500名、サブスク500名。
